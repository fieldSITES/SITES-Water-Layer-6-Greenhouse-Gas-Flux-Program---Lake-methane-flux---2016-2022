# SITES-Water-Layer-6-Greenhouse-Gas-Flux-Program---Lake-methane-flux---2016-2022
Collection of Greenhouse Gas (GHG) Flux data processing scripts from five lakes (stations), i.e. Almbergasjön (Abisko), Erken (Erken), Erssjön (Skogaryd), Feresjön (Asa) and Stortjärn (Svartberget), linked to the Thematic Program SITES Water, for the years 2016-2022.

This repository intends to describe data and scripts used in example analyses of methane data from 2016-2022 generated by the Swedish SITES Water Program.

Python script files:
Each script file has annotations for explanations of some details. Below is an overview.

1.	SITES-W_261107-mesanT-wT.py
Model to derive hourly surface water temperatures in lakes from local air temperatures interpolated form national weather monitoring by the Swedish Meteorological and Hydrological Institute (SMHI) via their MESAN interpolation product. This model is generated by fitting to locally measured surface water temperatures during CH4 flux measurements on each lake.
Output: pkl-file with hourly surface water temperatures for all lakes during 2016-2022 for use in extrapolation over time (separate script below).

2.	SITES-W_CH4_261107_dz_0-2-4_Tw_fr_TAM_MC.py
Script for main calculations of SITES lake CH4 flux and concentration patters. The script is numbered by sections to explain what different parts do. The operations performed includes:
    - Gathering, selecting and organizing data to use for different operations.
    - Defining lakes and lake characteristics such as depth zones and their areas.
    - Integration of fluxes across depth zones.
    - Integration of fluxes across the whole lake area accounting for the area of the different depth zones.
    - Establishing flux-temperature relationships based on best fit with empirical observations, 
    thereby also determining temperature-normalized fluxes and the temperature response factor.
    - Performing a Monte-Carlo extrapolation of fluxes across the years 2016-2022 
    including calculating among-year anomalies for each lake.
    - Generating an output pkl-file for the Monte-Carlo extrapolation for plotting and 
    statistical tests in separate script.
    - Making various plots.
    - IMPORTANT: Making critical selections - i.e. whether the run should focus on total flux (Ftot), diffusive flux (Fdiff), or surface water CH4 concentrations (Caq), which water temperatures to use, threshold temperatures in each lake to define the open-water season duration, and number of iterations in the Monte-Carlo extrapolation among years.  

3.	SITES-W_CH4_261107_Tw_fr_TAM_MCplotsanalysis.py
Using Monte-Carlo extrapolation output (pkl-file) from 2. SITES-W_CH4_261107_dz_0-2-4_Tw_fr_TAM_MC.py to generate boxplots, integrated yearly data and making statistical tests.
